📄

Result Data (result_data)

Required: roll_no, batch, semester, branch, programme
Key fields: exam_month (text e.g. November 2024), appeared (A), pf_status (P/F), student_name, sgpa, cgpa
Accepts: .xlsx or .csv

📊

Course Wise Data (result_data_coursewise)

Required: roll_no, batch, semester, branch, subject_name
Key fields: grade (O/A+/A/B+/B/C/F/AB), ta_marks, mse_marks, ext_marks, total_marks, exam_month, curriculum

🎓

Graduants Data (graduants)

Required: programme, academic_year, current_batch, branch, htno
Key fields: student_name, division (FIRST CLASS / SECOND DIVISION / PASS CLASS), backlog_status

📝

Admissions Data (result_admissions)

Required: roll_no
Key fields: admission_type (Regular In Take / Regular Lateral In Take / EWS / EWS_L)
